NowPlaying Relay

An Apple Music player that relays what you're listening to via webhooks.

What It Does

NowPlaying Relay is a full-featured Apple Music player with one twist: it can relay your currently-playing track info to any webhook endpoint you configure. Use it to power now-playing widgets, Discord bots, smart home displays, or anything else you can dream up.

Features

  • Full Apple Music player - Browse your library, search the catalog, view lyrics, manage queues
  • Webhook relay - Send track metadata to any HTTP endpoint when playback changes
  • Multiple endpoints - Configure as many webhook destinations as you need
  • Flexible auth - Bearer tokens, custom headers, or no auth
  • Event filtering - Choose which playback events trigger a relay
  • Activity log - Monitor delivery status, response times, and retry history
  • Privacy-first - No analytics, no tracking, no accounts. Your data stays yours.

Requirements

  • iOS 17.0 or later
  • Active Apple Music subscription
